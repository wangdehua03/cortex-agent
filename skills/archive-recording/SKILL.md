# 档案录入技能

## 概述

将分散在文件夹中的文档（Word、PDF 等）按既定规则提取元数据，并批量录入到 `档案信息.xlsx` 中。

## 适用场景

- 桌面存在 `档案信息.xlsx` 目标表
- 桌面存在 `录入规则.txt` 规则文件
- 待录入文档集中存放在某个文件夹中
- 需要从文档正文中提取年度、题名、文件形成时间、所属部门等信息

## 标准操作流程（SOP）

### 1. 读取规则

1. 定位桌面上的 `录入规则.txt`。
2. 逐条读取并整理为字段-规则对照表，尤其注意默认值和判定条件。

### 2. 查看目标表结构

1. 使用 `read_excel` 读取 `C:\Users\Dell\Desktop\档案信息.xlsx`。
2. 记录全部列名及顺序，确认哪些列需要人工填写，哪些列可由规则推导。

### 3. 扫描待录入文件夹

1. 使用 `run_shell` 或 `Get-ChildItem` 列出目标文件夹中所有文件及其扩展名。
2. 按文件类型（`.docx`、`.pdf` 等）分组，规划读取方式。

### 4. 提取文档元数据

1. **文书分类**：如无特殊说明，默认 `公文`。
2. **内容分类**：文档含文号或期数 → `发文`；否则 → `签报`。
3. **全宗号**：默认 `001`。
4. **年度**：从题名、落款时间或正文中提取 4 位年份。
5. **题名**：通常取文件名或文档标题；若文档标题更正式，优先使用文档标题。
6. **保管期限**：默认 `永久`。
7. **文件形成时间**：提取文档中的完整日期表述（如 `2024年6月12日`）。
8. **密级**：文档含 `工作秘密` 或 `内部` → `工作秘密`；否则 → `非密`。
9. **所属部门**：提取文档中落款部门或发起单位，如 `大商所某部门`、`大连飞创信息技术有限公司` 等。
10. **所属分部**：默认 `大连商品交易所`。

### 5. 写入 Excel

**推荐方式**：使用 `write_excel` 工具。

- 必须构造包含**全部列**的 Markdown 表格。
- 对于本次无需填写的列，使用**空字符串 `''` 占位**，确保列不错位。
- 写入后**必须重新读取 Excel**，逐列核对数据是否落在正确字段下。

**备用方式**：若 `write_excel` 写入后发现列错位，可改用 Python `openpyxl` 脚本精确控制列写入，但应优先修正 Markdown 表格后重新使用工具。

### 6. 校验

1. 读取写入后的 Excel，核对每行每列。
2. 对关键字段（年度、文件形成时间、密级、内容分类）进行抽样复核。
3. 检查是否有空列导致整体偏移。

## 关键注意事项

### 列对齐是最大坑点

- `write_excel` 按 Markdown 表头顺序写入，如果漏掉中间列，后续数据会整体前移。
- **正确做法**：在构建 DataFrame / Markdown 表格时，把所有列名写全，无值列用空字符串填充。

### 内容分类判定

- 不要只看标题，必须打开文档正文检查是否有文号或期数。
- 会议纪要类的 `第X期（总第X期）` 也属于期数，应判定为 `发文`。

### 所属部门提取

- 优先查找落款单位或落款部门。
- 若文档由子公司/合作单位发起，应如实填写该单位名称，不要默认写 `大商所`。

### 文件形成时间

- 提取完整的年月日字符串，保持原文档表述风格。
- 若文档中只有年份，至少填写年份，并记录不确定性。

## 示例

目标表字段：

```
ID, 分类号, 文书分类, 内容分类, 所属项目, 档号, 全宗号, 门类号, 档案分类, 年度, 题名, 保管期限, 文件形成时间, 密级, 所属部门, 所属分部
```

|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 |  | 公文 | 发文 |  |  | 001 |  |  | 2024 | 数据治理工作小组会议纪要 | 永久 | 2024年6月12日 | 非密 | 大连商品交易所办公室 | 大连商品交易所 |

## 常见错误

1. **列错位**：漏写空列导致后续字段前移。
2. **内容分类误判**：未检查正文，仅凭标题判断。
3. **年度遗漏**：未从落款时间提取，仅依赖文件创建日期。
4. **密级误判**：未扫描全文关键词。
5. **所属部门遗漏**：未查看文档落款。
